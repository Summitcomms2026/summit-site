# summit_design_system.md

## Purpose of this file

This file defines the front-end design language for Summit Communication Group.

It governs:
- layout principles
- grid and spacing
- typography
- colour and contrast
- panel rhythm
- component styling
- motion and transitions
- responsive behaviour
- media treatment
- form design
- card design
- visual hierarchy
- restraint rules

If:
- `summit_soul.md` defines what Summit is
- `summit_voice.md` defines how Summit sounds
- `summit_site_architecture.md` defines how Summit is organised
- `summit_build_system.md` defines how Summit is built

then this file defines how Summit should look and feel on screen.

This is not merely a style guide.
It is the compositional system that gives the site its calm authority.


## Design North Star

Summit should feel:
- architectural
- editorial
- intentional
- international
- restrained
- technologically assured
- culturally literate
- premium without ornament

The design must remain strong when stripped back to:
- typography
- spacing
- layout
- contrast
- motion
- hierarchy

Photography and film may elevate the experience.
They must not carry it.

A useful shorthand:
Summit should feel like a luxury consultancy and media platform designed with the discipline of a serious product team.


## Core Design Influences

Summit’s design language may draw inspiration from:
- Matter Of Form’s sparse navigation, paced paneling and project-led homepage logic
- Wolff Olins’ concise work presentation and disciplined project taxonomy
- DLG’s blend of consultancy proof and editorial / insight authority
- Apple’s modular product storytelling, oversized spacing and local navigation discipline

These references are directional, not prescriptive.
Summit must not imitate their furniture.
It should borrow their discipline.


## Foundational Design Principles

### 1. Negative space is an active design tool
Summit should use generous whitespace to create:
- calm
- hierarchy
- authority
- legibility
- premium pacing

Headlines should have room to land before content begins.
Panels should not feel tightly packed.
Content density should be controlled.

### 2. Contrast creates rhythm
The site should use controlled contrast shifts:
- dark to light
- image-led to text-led
- mono to expressive
- expansive to dense

This contrast should create page rhythm without chaos.

### 3. Fewer elements, stronger hierarchy
Every panel should contain only what is necessary.
Do not solve weak hierarchy by adding more UI.

### 4. Typography does most of the emotional work
The type system should carry:
- tone
- pace
- emphasis
- refinement
- distinction

### 5. Movement should feel engineered
Motion is not decoration.
It is part of the choreography of attention.

### 6. Panels should vary in composition
The site should avoid repetitive block monotony.
Use variance in:
- column count
- media position
- panel tone
- card density
- directional flow

But always within a coherent system.


## Visual Character

Summit’s design should feel:
- British in restraint
- international in polish
- luxury-adjacent without cliché
- modern rather than nostalgic
- editorial rather than brochure-led
- designed, not merely themed

Avoid:
- decorative “luxury” tropes
- gold gradients
- over-textured backgrounds
- obvious prestige cues
- heavy faux-editorial affectation
- excessive shadows
- ornamental UI


## Grid System

### Core Grid Philosophy
Use a disciplined, flexible layout grid that supports:
- full-width cinematic moments
- narrow editorial reading widths
- two-column strategic layouts
- three-column capability and card systems
- asymmetric image-text compositions

### Recommended Desktop Grid
- 12-column grid
- generous outer margins
- strong container discipline
- no accidental full-width text unless intentionally designed

### Recommended Tablet Grid
- 8-column logic or equivalent responsive collapse

### Recommended Mobile Grid
- 4-column logic or equivalent responsive stack
- strong padding discipline
- no edge-cramped content

### Content Width Rules
Use 3 primary content widths:
- wide container for hero and cinematic sections
- medium container for strategic layouts
- narrow reading width for long-form editorial content

Text should never stretch so wide that it loses authority.


## Spacing System

Spacing should feel generous and systematic.

### Recommended Spacing Philosophy
Use a modular spacing scale.
For example:
- xs
- s
- m
- l
- xl
- xxl
- xxxl

### Section Spacing
Large panels should have substantial vertical spacing.
Headlines should sit noticeably apart from body copy.
Modules inside panels should breathe.

### Rules
- avoid cramped panel intros
- give headline blocks more room than body copy blocks
- use larger top padding than bottom padding where appropriate for dramatic entry
- maintain consistent rhythm across the page even when panel layouts vary

Negative space is one of the main luxury signals in the system.


## Typography System

Typography is central to Summit’s visual identity.

### Preferred Primary Sans
- SF Pro Display

Use for:
- major headlines
- subheads
- body copy
- navigation
- UI labels
- cards
- forms

If SF Pro Display cannot be licensed appropriately for the web, use a disciplined fallback system approved separately.
Do not substitute with a weak generic geometric sans without review.

### Preferred Emphasis Serif
- Big Caslon FB Bold Italic

Use for:
- emphasised headline words
- selected highlighted words in key strategic panels
- occasional editorial emphasis
- rare moments of cultural or emotional weight

This serif should be used sparingly.
Its power comes from restraint.

### Typographic Roles

#### 1. Hero / Major Headline Sans
- Font: SF Pro Display Medium
- Tracking: slightly tight
- Purpose: calm authority, modern clarity

#### 2. Hero / Emphasised Word Serif
- Font: Big Caslon FB Bold Italic
- Tracking: normal
- Purpose: cultural charge, heritage, emotion

#### 3. Strategic Body Copy
- Font: SF Pro Display Medium
- Tracking: neutral
- Leading: generous, editorial
- Purpose: clarity and rhythm

#### 4. Small UI / Labels
- Font: SF Pro Display Medium or Bold
- Purpose: metadata, labels, interface utility

### Headline Rules
Headlines should:
- be large
- be clean
- use short line counts where possible
- create strong pause before copy begins

### Body Rules
Body copy should:
- remain readable
- avoid narrow cramped leading
- feel editorial rather than corporate
- use a comfortable reading measure

### Emphasis Rules
The serif italic should not be sprayed across the interface.
Use it to mark genuinely important emotional or conceptual words.

If everything is emphasised, nothing is.


## Typography Reference from Existing Summit Work

Based on existing Summit slide design language:

### Large Headline Sans
- Font: SF Pro Display Medium
- Approx. tracking: tight / around -30 in presentation use
- Use case: major philosophical or strategic panel headlines

### Large Emphasised Word
- Font: Big Caslon FB Bold Italic
- Tracking: normal
- Use case: luxury-signalling or emotionally resonant keyword within a headline

### Body Copy
- Font: SF Pro Display Medium
- Tracking: normal
- Leading: generous
- Use case: supporting strategic explanation

### Design Rule
Carry the spirit of this system into the web, not necessarily the exact point sizes of the deck.

Web typography must be responsive and optical, not literal.


## Type Scale

The site should use a clear responsive type scale.

### Suggested Hierarchy
- Display XL
- Display L
- H1
- H2
- H3
- H4
- Body L
- Body
- Small / Meta
- Micro / Utility

### Rules
- H1 should feel decisive and spacious
- H2 should be visually strong enough to anchor a full panel
- body copy should remain elegant and quiet
- metadata should not become visually noisy

The scale should work in dark and light sections equally well.


## Colour System

The palette should be restrained and architectural.

### Core Palette
Use a neutral-led system:
- deep near-black
- warm white or soft off-white
- cool greys / warm greys for hierarchy
- restrained accent colours only where strategically justified

### Contrast Philosophy
The site should make deliberate use of:
- dark panels
- light panels
- occasional image-led panels
- mono sections
- negative space-led sections

These tonal changes create rhythm.

### Rules
- avoid loud brand colours unless strategically essential
- avoid gratuitous gradients
- avoid luxury cliché metallic effects
- keep colour subordinate to typography and structure

Accent colour, if introduced, should be used for:
- active states
- links
- minor highlights
- selected interaction cues

Never for noise.


## Dark / Light Panel System

One of the defining visual rhythms of the site should be controlled alternation between dark and light environments.

### Dark Panels
Use for:
- hero moments
- cinematic showreel sections
- media-property sections
- closing statements
- emotionally weighty transitions

Dark panels should feel:
- immersive
- calm
- expensive
- highly legible

### Light Panels
Use for:
- strategic explanation
- service clarity
- editorial readability
- card grids
- proof layers

Light panels should feel:
- precise
- intelligent
- breathable
- editorial

### Rule
Do not alternate dark and light purely mechanically.
Use contrast to create narrative pacing.


## Panel Rhythm

Pages should feel composed through variation.

### Approved Panel Modes
- full-width hero
- large text + minimal support copy
- split image / text
- asymmetric image / text
- three-column capability block
- card grid
- dense editorial list
- testimonial block
- cinematic media panel
- quote-led panel
- download / asset panel
- closing CTA panel

### Variance Rules
Successive panels should vary in:
- density
- tone
- visual mass
- content mode

But the site should still feel like one system.

### Three-Column Rule
Three-column layouts are encouraged for:
- capabilities
- sectors
- feature clusters
- proof blocks
- editorial category groupings

They should feel elegant, not dashboard-like.


## Motion System

Motion should feel luxurious through control, not flamboyance.

### Motion Characteristics
- smooth
- understated
- precise
- unhurried
- elegant
- technically assured

### Motion Use Cases
- menu open / close
- panel reveal
- hover transitions
- image parallax, if subtle
- tab switching
- card interaction
- video loading
- button feedback
- sticky nav behaviour

### Rules
- no gratuitous bounce
- no loud spring effects
- no flashy scroll gimmicks
- no motion for its own sake
- animation must support hierarchy and user orientation

### Transition Philosophy
Panels should feel like they reveal themselves.
They should not lurch into view.

### Motion Tempo
Prefer:
- fast enough to feel modern
- slow enough to feel considered

The best reference is not “exciting”.
It is “effortless”.


## Navigation Design

### Sticky Top Navigation
The top navigation should remain:
- minimal
- stable
- lightweight
- sharply legible

Required order in normal state:
- Menu
- Brand
- Design Tomorrow

This order is prescriptive.

### Expanded Mega Menu
The expanded mega menu should follow the interaction logic and overall feel of Matter Of Form’s menu system.

It should feel like a designed space, not a dropdown.

It should include:
- the sticky top navigation preserved in place
- primary navigation
- secondary / utility links
- selected editorial feed from The Future of Luxury
- bottom utility bar

The mega menu should open as a full designed environment with calm motion, strong spacing and clear hierarchy.

### Expanded Menu
The expanded menu should feel like a designed space, not a dropdown.

It should combine:
- primary navigation
- secondary utility links
- selected editorial feed
- bottom utility bar

### Sticky Bottom Bar
This should reinforce:
- positioning
- contact route
- international credibility

### Navigation Rule
Navigation should not feel busy.
Its purpose is confidence, not feature density.


## Buttons and CTA Styling

Buttons should feel:
- calm
- exact
- editorial
- premium

Avoid:
- over-rounded generic SaaS buttons
- oversized call-to-action blocks
- loud hover effects
- glossy or faux-premium treatments

### Primary CTA
Should feel clean and assertive.

### Secondary CTA
Should feel lighter, text-led or lower emphasis.

### Tertiary CTA
May simply be a text link with a directional cue.

Directional arrows may be used, but with restraint.

Rule:
The CTA system should feel like part of the typography system, not a separate species.


## Card System

Cards should be elegant containers, not generic UI boxes.

### Card Types
- article card
- case-study card
- podcast episode card
- guest / proof card
- sector / capability card

### Card Rules
- strong hierarchy
- clear metadata
- calm spacing
- no excessive borders
- minimal visual clutter
- hover state should feel intelligent and restrained

Cards may use:
- image-led mode
- text-led mode
- mixed mode

Do not force every card into the same shape if the content type benefits from controlled variation.


## Content Density Rules

The site should move between:
- sparse high-impact sections
- moderate-density explanation sections
- denser editorial or archive sections

### Sparse Sections
Use for:
- hero
- manifesto lines
- transitions
- cinematic moments

### Moderate Sections
Use for:
- value proposition
- service explanations
- positioning panels

### Dense Sections
Use for:
- article archives
- season overviews
- transcripts
- work grids

Density should feel intentional.
It should not feel like some panels were finished and others gave up halfway through.


## Media Treatment

Media is important, but it must live inside the system.

### Images
Should be:
- editorial
- well-cropped
- compositional
- supportive of hierarchy

### Video
Should be:
- cinematic
- properly framed
- muted on autoplay by default where appropriate
- controlled in proportion and position

### Showreels
Should be treated as:
- manifesto devices
- proof of taste
- controlled immersive panels

### Rules
- do not let media dominate all panels
- do not build page rhythm around constant video
- do not rely on media to make a panel interesting

The architecture must still hold without it.


## Form Design

Forms should feel:
- elegant
- discreet
- easy to use
- well spaced
- calm

Avoid:
- clumsy plugin defaults
- overly boxed fields
- noisy validation states
- generic CRM form ugliness

### Form Principles
- clear labels
- comfortable spacing
- controlled field widths
- intelligent confirmation states
- no unnecessary fields at first glance

The Connect / Contact interface should feel like part of the site’s designed logic, not a bolted-on utility.


## Editorial Reading Experience

The Future of Luxury and podcast transcripts must feel premium to read.

### Reading Layout Rules
- narrow reading measure
- generous line-height
- clear H2/H3 hierarchy
- quiet metadata
- ample space above and below pull quotes
- considered in-article media placement

### Pull Quotes
Should be typographically strong but not melodramatic.

### Related Content Modules
Should feel editorial and useful, not algorithmically spammy.

Reading should feel like a privilege, not a chore.


## Podcast Design Rules

Tastemakers pages should feel like media property pages, not generic podcast embeds.

### Key Design Priorities
- strong series identity
- clean episode hierarchy
- season logic
- transcript readability
- platform utility without clutter
- audio-first but not visually impoverished

Use:
- large episode hero
- calm player block
- structured transcript
- guest module
- related article / related episode modules


## Responsive Design Behaviour

The design system must survive across breakpoints.

### Mobile
- preserve elegance
- preserve hierarchy
- maintain generous spacing
- stack intelligently
- keep nav and CTA behaviour clean

### Tablet
- avoid awkward between-states
- preserve panel rhythm
- allow multi-column layouts only where they still read well

### Desktop
- use space confidently
- allow generous negative space
- preserve asymmetry where useful
- never let width weaken hierarchy

Rule:
Do not reduce the mobile experience to compressed leftovers.


## Accessibility Design Rules

Summit’s design should remain accessible.

Minimum design requirements:
- strong contrast
- visible focus states
- no overly faint text
- scalable type
- readable line lengths
- calm but clear link treatment
- forms that remain legible
- motion that does not create disorientation
- support for reduced-motion preferences

Accessibility is part of refinement.


## Anti-Patterns

Summit’s design system must avoid:
- luxury cliché visuals
- overuse of serif emphasis
- cramped layouts
- over-designed motion
- SaaS-style component noise
- endless image walls
- colour without hierarchy
- decorative complexity
- heavy-handed “editorial” cosplay
- all-dark-all-the-time monotony
- repetitive panel sameness
- page-builder visual chaos

If a design choice makes the site feel more generic, noisier or less composed, it is probably wrong.


## Design Success Criteria

The design system is successful when:
- the site feels premium in wireframe
- headlines land with authority
- body content breathes
- dark and light sections create rhythm
- panels vary without feeling inconsistent
- motion feels effortless
- cards feel editorial, not templated
- forms feel designed, not plugin-made
- reading feels pleasurable
- the interface survives without hero photography
- the system feels internationally credible and distinctly British in restraint

In short:
The design is successful when it makes Summit feel like a serious digital house, not a decorated agency site.


## How AI Should Use This File

When generating front-end ideas, layout logic, component styles or design decisions for Summit, AI should:
- prioritise typography, spacing and hierarchy over decoration
- use negative space generously
- employ dark/light rhythm deliberately
- vary panel compositions in a controlled way
- treat motion as part of the experience
- preserve restraint and British composure
- ensure the system remains strong without media
- avoid over-design and luxury cliché

If a design suggestion looks expensive but feels structurally weak, reject it.


## Final Design Ethos

Summit’s design system should feel like a composed conversation between architecture, typography, motion and silence.

Not loud.
Not ornamental.
Not temporary.

It should feel designed to last.
